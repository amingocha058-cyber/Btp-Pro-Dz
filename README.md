# Btp Pro Dz

**Open-source offline engineering and construction calculations Android app.**

Btp Pro Dz is an Android application for construction professionals, design offices, skilled tradespeople, and people planning to build their own homes.

## Technology

- Kotlin
- Jetpack Compose
- Android Gradle Plugin
- Minimum Android version: Android 7.0 (API 24)
- Package name: `dz.btpprodz`

## Project goals

- Work offline; no internet connection is required for core calculations.
- Arabic and French user interface.
- Construction and engineering calculation modules.
- Material quantities and price history.
- Independent labor-cost calculations linked to work items.
- Custom units entered by the user.
- Estimates (Devis) focused on calculation details, including TVA.

## Build

Open this repository in Android Studio and let Gradle sync. The project uses Java 17 and Android SDK 36.

## Project status

Initial Android/Jetpack Compose foundation. Engineering calculation modules are being developed incrementally.
